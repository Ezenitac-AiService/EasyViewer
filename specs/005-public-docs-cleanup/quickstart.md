# Quickstart: 검증 절차

## 1. 자동 검사 (SC-001, SC-003–SC-005, SC-007–SC-009)

```bash
npm run verify
```

기대 결과: 공개 문서 검사 D1–D7, 지원 범위·배너·금지 표현·정체성·Windows 재유입 검사가 모두 통과한다.

## 2. 첫 화면 점검 (SC-002)

GitHub에서 `README.md`와 `README.en.md`를 열고 헤더(첫 `##` 제목 앞)만 읽는다. 다섯 질문에 답할 수 있는지 표로 적는다: 무슨 앱인가, 원저작자 앱과의 관계, 지원 등급, 받는 곳, macOS 처음 실행 방법. 배지 6개를 눌러 대상이 맞는지 확인한다.

## 3. 내용 보존 (SC-006)

`verification/readme-inventory.md`의 모든 항목에 정리 후 위치가 있는지 확인한다. 기여 가이드 국문·영문 양쪽에 같은 항목이 있는지 본다.

## 4. 조작 방법 (FR-005)

조작 표의 항목마다 그 동작을 확인하는 자동 테스트를 `verification/controls.md`에 적는다. 테스트가 없는 항목은 표에서 뺀다(FR-005).

## 5. 형제 프로젝트 문장 복사 없음 (FR-012)

정리 후 공개 문서에서 ImageViewer `README.md`·`README.en.md`와 같은 문장(한 문장 단위, 코드·명령·배지 URL 형식 제외)이 없는지 대조해 결과를 적는다.
