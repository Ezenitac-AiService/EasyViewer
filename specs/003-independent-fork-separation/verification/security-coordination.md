# 원저작자 보안 통지 요약 (T013, T014)

data-model §6, research R11에 따른 요약이다. 결함 세부와 재현 방법은 적지 않는다.

| 필드 | 내용 |
|---|---|
| 통지 날짜 | 2026-11-18 |
| 경로 종류 | 원저작자와의 비공개 서신(메인테이너 직접 발송). 공개 이슈·PR·토론에는 결함 내용을 쓰지 않았다 |
| 항목 범주와 개수 | 범주 5개: 경로 검증, SSRF, CSP, 자격증명, 콘텐츠 정화. 범주 단위로만 알렸고 개별 결함 목록과 개수는 보내지 않았다 |
| 원저작자 최신 릴리스 대조 | 하지 않음. 각 범주가 원저작자 최신 릴리스에 남아 있는지는 T012에서 대조한다. 대조 결과 해당이 없는 범주가 있으면 원저작자에게 정정해 알린다 |
| 원저작자 응답 | 통지를 확인했고 수정할 예정이라고 회신함 |
| 미수정 결함 공개 기준 | 통지 후 90일(2027-02-16)까지 공개하지 않는다. 그 전에 원저작자가 수정을 게시하면 그 뒤에 공개 여부를 정한다 |
| 기록자 | Claude Code(메인테이너 구두 보고 기준), 2026-11-19 |

같은 서신에 분리 사전 고지도 담았다. 고지 기록은 `upstream-notice.md`에 있다.
