# Windows 전환 안내

이 포크는 Windows 배포와 공식 지원을 중단했습니다.

<!-- support-scope:start -->
이 포크는 **macOS · iOS · Linux**를 중점 지원합니다. iOS는 공개 배포 채널 없이 소스 빌드로만 제공합니다.
Android는 우선순위를 낮춘 유지 플랫폼으로 계속 배포합니다.
**Windows는 이 포크의 지원·배포 대상이 아닙니다. Windows에서는 원저작자의 [EasyViewer](https://github.com/edith2580/EasyViewer)를 사용하세요.**
웹 브라우저 실행은 개발 보조용입니다.
Linux는 Ubuntu 22.04 이상 또는 동급 배포판(deb·AppImage, WebKitGTK 4.1, X11·Wayland)에서 검증합니다. 그 밖의 배포판은 동작할 수 있으나 검증하지 않습니다.
<!-- support-scope:end -->

이 문서는 이 포크가 게시했던 Windows 프리릴리스(`v0.1.6-alpha`, `v0.1.6-beta`)를 쓰던 분이 원저작자의 [EasyViewer](https://github.com/edith2580/EasyViewer)로 옮기는 방법을 설명합니다.

> **검증 상태**: 이 절차는 아직 실제 Windows 환경에서 끝까지 검증하지 않았습니다(작업 T048). 검증을 마치면 이 표시를 지우고 확인한 원저작자 앱 버전을 적습니다.

## 먼저 알아 둘 점

- **두 앱의 데이터 형식이 다릅니다.** 이 포크는 앱 내부 데이터 형식을 버전 2로 올렸고, 원저작자 앱은 버전 1을 씁니다. 원저작자 앱은 이 포크가 만든 서재 데이터를 읽지 못합니다.
- 두 앱은 같은 데이터 폴더를 씁니다. 그래서 이 포크의 데이터가 남아 있는 상태로 원저작자 앱을 설치하면, 원저작자 앱이 서재를 열지 못하고 빈 화면이나 오류를 보일 수 있습니다.
- 데이터 내보내기 기능은 없습니다. 책 파일은 그대로 옮길 수 있지만, 아래 항목은 옮겨지지 않습니다.

### 옮겨지지 않는 항목(손실 항목)

- 읽기 진행률
- 책갈피
- 표시 설정(테마, 글꼴, 보기 모드 등)
- WebDAV 자격증명(원저작자 앱에서 다시 입력해야 합니다)

## 전환 절차

1. **책 파일 백업**: 파일 탐색기 주소창에 `%APPDATA%\com.edith.easyviewer\books`를 입력해 열고, 안의 파일을 다른 폴더(예: `문서\EasyViewer-백업`)로 복사합니다. 앱에서 저장 폴더를 따로 지정했다면 그 폴더를 백업합니다.
2. **포크 앱 제거**: 설정 → 앱 → 설치된 앱에서 EasyViewer를 제거합니다. 포터블 ZIP을 썼다면 압축을 푼 폴더를 지웁니다.
3. **포크 앱 데이터 정리**: `%LOCALAPPDATA%\com.edith.easyviewer` 폴더의 이름을 `com.edith.easyviewer.fork-backup`처럼 바꿉니다. 이 폴더에 이 포크의 서재 데이터(형식 버전 2)가 들어 있습니다. 바로 지우지 말고 이름만 바꿔 두면, 문제가 생겼을 때 되돌릴 수 있습니다.
4. **원저작자 앱 설치**: [원저작자 릴리스 페이지](https://github.com/edith2580/EasyViewer/releases)에서 최신 Windows 설치 파일을 내려받아 설치합니다.
5. **책 다시 가져오기**: 원저작자 앱에서 1단계에서 백업한 책 파일을 다시 가져옵니다.
6. WebDAV 연결을 쓰던 경우 원저작자 앱에서 연결과 비밀번호를 다시 등록합니다.

## 3단계를 건너뛰었을 때

원저작자 앱이 서재를 열지 못하거나, 빈 서재가 보이거나, 저장소 오류가 표시될 수 있습니다. 이 포크가 남긴 데이터(형식 버전 2)를 원저작자 앱(형식 버전 1)이 열 수 없기 때문입니다.

**복구 방법**: 원저작자 앱을 종료하고 3단계(`%LOCALAPPDATA%\com.edith.easyviewer` 이름 바꾸기)를 실행한 뒤 다시 실행하고, 5단계부터 진행합니다.

## 백업 없이 원저작자 앱을 먼저 설치했을 때

`%APPDATA%\com.edith.easyviewer\books`의 책 파일은 원저작자 앱을 설치해도 지워지지 않습니다. 원저작자 앱을 종료하고 이 폴더의 파일을 다른 곳에 복사한 뒤, 3단계부터 진행하세요.
