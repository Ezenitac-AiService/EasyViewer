# 모바일(iOS·Android) 이전 안내

<!-- support-scope:start -->
이 포크는 **macOS**를 중점 지원합니다.
iOS는 우선순위를 낮춘 유지 플랫폼이며, 공개 배포 채널 없이 소스 빌드로만 제공합니다.
Linux·Android는 **테스트용 빌드**로만 배포합니다. 품질·기능 동등성·실기기 검증·대응 일정을 보장하지 않습니다.
**Windows는 이 포크의 범위가 아닙니다. Windows에서는 원저작자의 [EasyViewer](https://github.com/edith2580/EasyViewer)를 사용하세요.**
웹 브라우저 실행은 개발 보조용입니다.
Linux 테스트용 빌드는 Ubuntu 22.04 이상 또는 동급 배포판(deb·AppImage, WebKitGTK 4.1, X11·Wayland)에서 빌드합니다. Android 테스트용 빌드는 Android 7.0(API 24) 이상이 대상입니다.
<!-- support-scope:end -->

이 포크의 앱은 첫 독립 릴리스부터 이름이 **Pagelight**로, 앱 식별자가 `com.ezenitac.easyviewer`로 바뀝니다. 이전 버전(식별자 `com.edith.easyviewer`)과는 다른 앱이 됩니다.

## 무엇이 달라지나요

- **새 앱으로 따로 설치됩니다.** Android와 iOS는 식별자가 다른 앱을 업데이트로 보지 않습니다. Pagelight를 설치해도 이전 앱은 그대로 남아 있고, 홈 화면에 두 앱이 함께 보입니다.
- **데이터를 자동으로 옮기지 않습니다.** 모바일 운영체제는 앱마다 저장 공간을 따로 두어 다른 앱의 데이터를 읽을 수 없습니다. 그래서 macOS·Linux처럼 첫 실행 때 자동으로 옮기는 기능이 없습니다.
- **Android 서명 키도 바뀝니다.** Pagelight는 이 포크가 소유한 고정 키로 서명합니다([Android 서명 안내](android-signing.md)).

## 옮기는 방법

### 1. 읽기 위치와 책갈피: WebDAV 동기화

이전 앱에서 WebDAV 동기화를 쓰고 있었다면 다음 순서로 옮길 수 있습니다.

1. **이전 앱**에서 동기화를 한 번 실행해 최신 읽기 위치와 책갈피를 서버에 올립니다.
2. **Pagelight**에서 같은 WebDAV 연결을 다시 추가합니다. 비밀번호는 다시 입력해야 합니다.
3. 책 파일을 가져온 뒤(아래 2단계) 동기화를 실행합니다. 이전 앱에서 쓰던 것과 내용이 같은 파일이면, 서버에 올려 둔 읽기 위치와 책갈피를 받아옵니다. 내용이 다른 파일(다른 판본 등)은 같은 책으로 보지 않습니다.

### 2. 책 파일: 다시 가져오기

- Pagelight에서 **[책 추가]**로 기기에 있는 EPUB·TXT 파일을 다시 가져옵니다.
- WebDAV 서버나 URL에 있던 책은 Pagelight에서 다시 내려받습니다.
- 이 포크의 이전 버전에는 앱 안에 저장된 책 파일을 다른 앱으로 내보내는 기능이 없습니다. 원래 받아 둔 파일이나 서버의 파일을 쓰세요.

## 옮기지 못하는 항목

| 항목 | 옮겨지나요 | 대신 할 일 |
|---|---|---|
| 책 파일 | 자동으로는 안 됨 | [책 추가]로 다시 가져오기 |
| 읽기 진행률 | WebDAV 동기화를 쓰면 됨 | 동기화를 쓰지 않았다면 다시 시작 |
| 책갈피 | WebDAV 동기화를 쓰면 됨 | 동기화를 쓰지 않았다면 다시 추가 |
| 표시 설정(글꼴·테마·여백) | 안 됨 | Pagelight에서 다시 설정 |
| WebDAV 비밀번호 | 안 됨 | 연결을 추가할 때 다시 입력 |

## 이전 앱은 언제 지우나요

- Pagelight에서 책과 읽기 위치를 확인한 **뒤에** 이전 앱을 지우세요.
- 이전 앱을 지우면 그 앱에 저장된 서재와 설정도 함께 지워지며, 되돌릴 수 없습니다.
- WebDAV 동기화를 쓰는 경우, 지우기 전에 이전 앱에서 마지막으로 한 번 동기화하세요.

## 데스크톱은 다릅니다

macOS와 Linux에서는 Pagelight를 처음 실행할 때 이전 버전의 서재와 설정을 한 번 복사합니다. 원본은 그대로 남습니다. 자세한 동작은 앱 안의 안내를 따르세요.
